# Image Assets

## Avatar

Place your professional photo here as `avatar.jpg` for the homepage.

Recommended specs:
- Format: JPG or PNG
- Size: 400x400px or larger (square)
- Professional headshot or profile photo

Current homepage (_index.md) references: `img/avatar.jpg`

## Favicons

- `favicon.svg` - Vector icon (primary)
- `favicon.png` - PNG fallback
